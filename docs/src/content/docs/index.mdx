Alibi `0.5.0` is available on [crates.io](https://crates.io/crates/alibi) and targets Better Auth `1.7.7`.

## One auth instance. The features you need.

```rust
use alibi::plugins::{EmailPasswordPlugin, OrganizationPlugin, TwoFactorPlugin};
use alibi::{AuthBuilder, AuthResult, AuthSchema, Alibi};

async fn with_features<S: AuthSchema>(builder: AuthBuilder<S>) -> AuthResult<Alibi<S>> {
    builder
        .plugin(EmailPasswordPlugin::new().enable_signup(true))
        .plugin(TwoFactorPlugin::new())
        .plugin(OrganizationPlugin::new())
        .build()
        .await
}
```

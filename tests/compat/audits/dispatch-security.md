# Dispatch security, path and media policies (#180)

Authority is the published Better Auth 1.7.6 router/BetterCall body parser and actual configured applications, not a Rust-derived expectation. `tests/core/dispatch.test.ts` uses the official client, actual HTTP including chunked bodies, application before-hook receipts, and real SQL snapshots of every owner and foreign row. No observation comparator or normalization exception changes.

Global middleware opt-outs are distinct. `AdvancedConfig.disable_csrf_check` is now `Option<bool>`: `None` retains the pinned legacy coupling to global origin opt-out, while explicit `Some(false)` preserves local form checks. `Some(true)` disables CSRF admission but redirect target validation remains. `disable_origin_check_paths` matches the exact normalized prefix or its slash-delimited descendants, never an unrelated peer. Foreign requests, guest navigation and trusted `Origin: null` controls retain original state/callback behavior. Null origin is inferred only with actual same-origin fetch metadata and the original request URL. Native embeddings can provide `AuthRequest::with_url`; Axum retains actual Host/URI and configured deployment scheme, ignoring untrusted forwarded headers. Broader proxy/base-URL discovery is independently tracked by #178.

Literal disabled paths reject before application middleware/hooks with Source's text NotFound response. Template strings do not disable an instantiated route. `skip_trailing_slashes` controls admission; matching routes and methods precede body/origin parsing and hooks. Actual POST, HEAD and PATCH controls preserve Source's empty 404 rather than Axum-generated 405/Allow. Arbitrary HTTP verbs outside the native transport enum remain part of #193; this owner makes no unsupported verb-equivalence claim.

The public `AuthPlugin::allowed_media_types` defaults to JSON; an empty list disables the restriction. Media declarations are trimmed/case-insensitive and checked with Source's substring behavior. Allowed bodies decode once into `ParsedRequestBody`, while original headers and bytes remain intact. The exact JSON prefix rule rejects malformed JSON before hooks. URL-encoded fields retain strings and last-value semantics. Text, stream, blob and buffer representations are kept distinct; object schemas inspect missing properties on opaque transport objects instead of reparsing their bytes as JSON. Schema rejection occurs after admitted application before-hooks and before route-local form CSRF checks, matching actual Source phase ordering.

Real multipart fields are decoded with multer, with file bytes/name/media retained in the public `MultipartFiles` extension. File values have Source's empty enumerable JSON projection and Blob validation type. Valid multipart sign-in using Source-admitted media text succeeds; missing boundary returns the actual empty 500 before hooks/writes. A file in the email field returns Source's exact schema error after its before hook without authentication state changes. Request bodies remain bounded by the existing accepted transport limits; no unbounded network read or application filesystem access is introduced.

Response repairs preserve Source's HTML Content-Type for its error page and OpenAPI UI. Native public `AuthResponse::html` retains its existing UTF-8 helper contract. Complete differential HTTP headers, cookies, cache-control and physical state remain in the owner observations. This does not claim every unrelated endpoint's response policy is settled.

Authoring evidence includes actual pre-fix differential failures for routing, null-origin inference, declared media whitespace and decoding/schema phase ordering. The frozen original binary fails the actual owner, while the repaired implementation passes. Additional multipart Source/native controls are actual successful/denied requests, not simulated handler outcomes. Existing native request tests now declare JSON media where they actually post JSON, retaining their meaningful expected authentication behavior. No tests solely mirror a helper algorithm, and no test-only production admission seams were added.
